MK2 ACTIVATOR FOR MASCHINE 3
============================

Lets you use the Maschine MK2 with Maschine 3.

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!
!!!  WARNING: MASCHINE JAM WILL STOP WORKING IN MASCHINE 3 WHILE THE MK2 IS ENABLED  !!!
!!!  Use "Restore original" to get the Jam back.                                     !!!
!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

BEFORE YOU START
- You need Maschine 3 installed and activated with Native Access.
  Tested with 3.6.0 and 3.7.1. Other 3.x versions work if the Activator recognizes them.
  (To check your version: open Maschine 3 > Help > About.)
- This is not official Native Instruments software. Use it at your own risk.

HOW TO ENABLE THE MK2
1. Close Maschine 3.
2. Double-click "MK2 Activator.exe".
3. Windows will ask whether to allow it to make changes: click "Yes".
   (It needs this to modify Maschine 3 inside Program Files.)
4. Click "Enable MK2".
5. Connect the MK2 and open Maschine 3.

HOW TO RESTORE THE ORIGINAL
Open "MK2 Activator.exe" again and click "Restore original".
You can also repair Maschine 3 in Native Access.

FAQ
- Windows or the antivirus says the app is dangerous:
  the app is not digitally signed, so Windows shows "Unknown publisher".
  In the blue SmartScreen window click "More info" > "Run anyway".
- It says "cannot be patched safely":
  the Activator did not find the code it expects in your Maschine 3. Nothing was changed.
- Native Access updated Maschine 3 and the MK2 stopped working:
  updates remove the patch. Open the Activator and click "Enable MK2" again.
- It cannot find Maschine 3:
  click "Choose another file..." and locate "Maschine 3.exe" in the folder where you installed it.
